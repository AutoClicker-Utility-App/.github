## 🚀 At a Glance
Auto Clicker for Windows automates the mouse clicks you would otherwise perform by hand, running them at a scheduled speed and location. It is aimed at software testers who need repeatable input, power users automating routine app steps, and anyone who wants to skip the monotony of manual clicking. You configure the timing and target once, then let the utility carry the load. Fast to set up and light on resources, it turns a repetitive chore into a set-and-forget task.

## 🎁 What You Get
| Feature | What it does for you |
|---------|----------------------|
| Speed control | Sets how quickly clicks fire, from a slow cadence to rapid, high-speed sequences. |
| Fixed positions | Locks clicks to exact coordinates so every one hits the same spot. |
| Click-type options | Lets you pick left, right, single, or double clicks for the task at hand. |
| Hotkey triggers | Starts and stops automation from the keyboard, no mouse needed. |
| Repeat scheduling | Runs a set number of clicks or loops continuously for long jobs. |

## 🎯 Quick Start
1. Open Auto Clicker and set your click speed.
2. Select the mouse button and click type.
3. Choose a fixed position or click at the cursor.
4. Set how many clicks to run, or loop endlessly.
5. Press the hotkey to start and press it again to stop.
